Instructions de Flux de Données : 1. Trigger : Electron (Node.js) détecte une partie ou une recherche. 2. Exécution : Node.js lance python src/python/data_processor.py --query {type} via un child_process. 3. Traitement : Python appelle l'API Deadlock, nettoie le JSON et calcule les probabilités de victoire/tags. 4. Retour : Python renvoie le JSON final via stdout. 5. Affichage : Electron reçoit le JSON et met à jour les 12 cartes du Frontend via IPC.
